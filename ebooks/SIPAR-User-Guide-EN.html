01 · INTRODUCTION

A more organized way to manage loans

SIPAR is the RPL Equipment Loan Information System, designed to support practical equipment management at SMK Negeri 5 Surakarta.

An equipment loan involves several details: who borrows an item, which equipment is needed, when it is collected, and when it is due back. Scattered records can make stock and transaction history difficult to monitor.

SIPAR brings these details together in a web application. Requests, reviews, handovers, and returns are recorded in a traceable workflow, with access based on each user's role.

02 · WEB FEATURES

Student menus available in the web app

Students use four main menus. Multi-item requests are part of the Equipment Catalog workflow, not a separate menu.

01 · Dashboard

A summary of available equipment, submitted requests, pending requests, and completed transactions.

02 · Equipment Catalog

Browse and search by name or code, check availability, select several equipment types, and submit one request. The catalog form allows at most one unit per type.

03 · Loan History

Review request status and details as a transaction progresses to completion.

04 · My Profile

View account information and manage the available profile and password settings.

Catalog request rulesLoan date is today · maximum duration is 5 days · every request awaits administrator review

02 · WEB FEATURES

Inventory controls and physical handover

Each role completes a different part of the workflow while keeping records connected.

ADMIN · Master data

Manage equipment, categories, and student accounts; review, approve, or reject requests.

ADMIN · Reports

Review transaction summaries and download available PDF or Excel reports.

TECHNICIAN · Handover

Find a transaction by booking code or student ID, then record Asset IDs/serial numbers, condition, and photo evidence.

TECHNICIAN · Return

Find a transaction, record item condition and photo evidence, and process returns item by item.

REQUEST→REVIEW→HANDOVER→RETURN

Stock is updated when a request is approved and when a return is recorded according to the equipment's condition.

04 · HOW TO USE THE WEB APP

Student · submit a loan request

Prepare the equipment you need, the usage dates, and the reason for borrowing before you start.

1
Sign in

Open the SIPAR address in a browser and sign in with your student account.

2
Find equipment

From the Dashboard, open Equipment Catalog. Search by name or code and check availability.

3
Select equipment

Choose Select Equipment for each item you need. Review your selection in the Loan panel.

4
Complete the form

Set the loan date (today), planned return date (within five days), and a clear purpose.

5
Review and submit

Make sure the item list is not empty. Select Submit Loan Request, review the confirmation, then choose Continue.

6
Track status

Open Loan History to check the status. A Pending request is awaiting administrator review.

If you need to make changes

Choose Cancel in the confirmation to return to the form. Review your item selections and details before submitting.

04 · HOW TO USE THE WEB APP

Administrator and technician · process a transaction

After a student submits a request, the administrator and technician continue the process according to their responsibilities.

Administrator

1
Open Loan Verification

Check the borrower's identity, item list, schedule, and purpose.

2
Make a decision

Approve if stock is available and the information is valid, or reject with a reason.

3
Manage data and reports

Update inventory in the relevant menus and use reports to review transactions.

Technician

1
Find the transaction

Use a booking code or student ID in Handover or Return.

2
Record the handover

Enter an Asset ID/serial number for each unit handed over, its condition, and requested photo evidence.

3
Record the return

Select the item and its observed condition, attach requested photos, and save the record.

Record the actual condition

Inspect each item physically. Its condition affects stock records; do not mark a unit before the inspection is complete.

05 · CONCLUSION

Accountable loans, well-managed inventory

SIPAR connects student requests with administrator review and technician handover and return records.

With a catalog, request form, transaction status, and operational notes in one application, users can follow equipment from request through return.

Reliable records still depend on using the correct role, checking stock, entering accurate information, and consistently recording equipment condition.
